# Security Policy

## Supported Versions

We release updates and patches for the current version of WaveForge hosted on GitHub Pages.

| Version | Supported          |
| ------- | ------------------ |
| Latest (`main` branch) | :white_check_mark: |
| Older commits | :x:                |

## Reporting a Vulnerability

We take the security of WaveForge seriously. If you discover a security vulnerability, please report it responsibly.

### How to Report

1. **GitHub Security Advisory / Private Disclosure**:
   If enabled on the repository, please use the **Report a vulnerability** button under the [Security tab](https://github.com/PROGAMERYT-op/WaveForge/security/advisories) on GitHub.

2. **GitHub Issues**:
   If private security advisories are not available, please open an issue on our [GitHub Issues](https://github.com/PROGAMERYT-op/WaveForge/issues) page with details of the vulnerability.

**Please do not publicly disclose details of unpatched security vulnerabilities prior to investigation.**

### What to Include in Your Report

* A description of the vulnerability and its potential impact
* Steps to reproduce the issue
* Any proof-of-concept code or demonstration
* Recommendations for remediation, if available

### Response Timeline

* **Initial Acknowledgment:** Within 48 hours of receiving your report.
* **Assessment & Fix:** We aim to investigate and address verified vulnerabilities as quickly as possible.

Thank you for helping keep WaveForge safe!
