About WaveForge

WaveForge is a professional-grade HTML5 Music Visualizer and Spectrum Analyzer using the Web Audio API.

Features include:

  • Real-time FFT analysis and waveform rendering.
  • Beat detection algorithms for dynamic visual reactivity.
  • Microphone input support for live audio visualization.
  • Customizable particle systems and glow effects.
  • Offline capability and highly optimized WebGL performance.

Upload your MP3, WAV, or OGG files to see your music come to life.
